# 變化球種 (Pitch Types) 與真實球路對應指南

本指南旨在協助球探系統 (Agent) 將真實世界中投手的球種，準確對應至實況野球 (Pawapuro) 的系統分類中。實況野球將球種以「方向」作為主要分類依據。

## 判斷邏輯概論

當分析投手的球路時，請依據以下步驟進行判斷：
1. **確認基礎球種**：是滑球、曲球、指叉、變速、還是伸卡？
2. **分析變化軌跡 (位移數據)**：
   - 純橫向？ -> 滑球系 / 噴射系
   - 斜向位移？ -> 曲球系 / 伸卡系
   - 垂直下墜？ -> 下墜系
3. **分析球速與變化幅度**：
   - 速度快、幅度小 -> 通常冠上 `H` (High-speed) 或歸類為卡特/SFF。
   - 速度慢、幅度大 -> 慢速系 (如スローカーブ)。

---

## 1. 直球系 (Straight) - 搖桿上
主要對應真實世界中不具備大幅度變化的快速球。

- **ストレート (四縫線直球)**: 預設球種。
- **ツーシームファスト (二縫線快速球)**: 具備些微尾勁的二縫線。若位移極大，可考慮移至噴射球系或伸卡系。
- **ムービングファスト (移動快速球)**: 軌跡不規則或帶有卡特/伸卡綜合特性的直球。
- **超スローボール (超慢速球)**: 實戰中極為罕見的小便球 (如多田野數人的超慢速球)。

## 2. 滑球系 (Slider) - 橫向變化 (非慣用手側)
主要對應往非慣用手側 (右投對右打外角) 產生「橫向」位移的球路。

- **スライダー (滑球)**: 標準滑球。橫向位移顯著，縱向位移較小。
- **Hスライダー (高速滑球)**: 球探報告指出「球速極快」(Hard Slider) 且變化較晚、幅度較小的滑球。
- **カットボール (卡特球/切球)**: Cutter。球速接近直球，在進壘時才發生微小且銳利的橫向變化。

## 3. 曲球系 (Curve) - 斜下變化 (非慣用手側)
主要對應往非慣用手側產生「斜向」下墜，或帶有明顯弧度的球路。

- **カーブ (曲球)**: 標準曲球。
- **スローカーブ (慢速曲球)**: 球速極慢 (Slow Curve)，通常用來破壞打者節奏，帶有高大弧線。
- **ドロップ (下墜球)**: 早期日職常見，強調幾乎純縱向掉落的曲球。
- **ドロップカーブ (下墜曲球)**: 現代常見的 12-6 曲球 (12-6 Curve)，垂直掉落幅度極大。
- **スラーブ (滑曲球)**: Slurve。橫向位移與縱向位移皆大的球種，介於滑球與曲球之間。
- **ナックルカーブ (彈指曲球)**: Knuckle Curve。通常球速比一般曲球快，且掉落軌跡銳利。
- **パワーカーブ (強力曲球)**: Power Curve。球速接近滑球，但帶有曲球的下墜弧度與銳利度。
- **Dスライダー (D滑球/下墜滑球)**: Drop Slider。真實世界中帶有明顯縱向掉落軌跡的滑球。**判斷關鍵**：如果球探報告稱其為滑球，但位移數據顯示具有大量的垂直下墜，且帶有斜向軌跡，應歸類於此。

## 4. 下墜系 (Fork) - 垂直下墜
主要對應幾乎沒有橫向位移，純粹往下掉落的球路。

- **フォーク (指叉球)**: 標準指叉球 (Forkball)。變化幅度極大，球速通常較直球慢 15-20km/h。
- **SFF (快速指叉球)**: Splitter。球速較快 (接近直球)，變化發生得晚，掉落幅度較指叉球小。
- **チェンジアップ (變速球)**: 標準變速球 (Changeup)，靠速差擾亂打者，軌跡為直線下墜。
- **Vスライダー (縱向滑球)**: Vertical Slider。**判斷關鍵**：真實世界的滑球，但幾乎沒有橫向位移，純粹像指叉球一樣垂直掉落 (如松井裕樹的滑球)。
- **パーム (掌心球)**: Palmball。靠手掌推擠投出，球速極慢且帶有些微不規則下墜。
- **ナックル (蝴蝶球/彈指球)**: Knuckleball。不旋轉，軌跡完全不規則。

## 5. 伸卡/螺旋系 (Sinker) - 斜下變化 (慣用手側)
主要對應往慣用手側 (右投對右打內角) 產生斜向下墜的球路。

- **シンカー (伸卡球)**: Sinker。右投手的標準下沉球，往右打者內角下方掉落。
- **スクリュー (螺旋球)**: Screwball。左投手的伸卡球在遊戲中預設為此名稱，或指極罕見的真實螺旋球。
- **Hシンカー (高速伸卡球)**: Hard Sinker。球速極快，下沉幅度較小，常被現代投手作為製造滾地球的主戰球路。
- **サークルチェンジ (圈指變速球)**: Circle Changeup。變速球的一種，但帶有明顯往慣用手側的尾勁 (類似伸卡軌跡)。若球探指出變速球會往右打內角跑，則歸類於此。
- **ファストチェンジ (快速變速球)**: 球速較快的變速球，類似直球直到最後才微幅下墜。
- **シンキングスプリット (下沉指叉球)**: Sinking Splitter。帶有伸卡橫向位移特性的快速指叉球。

## 6. 噴射系 (Shoot) - 橫向變化 (慣用手側)
主要對應往慣用手側純橫向竄動的球路。

- **シュート (噴射球)**: Shoot。往慣用手側產生明顯橫向位移。
- **Hシュート (高速噴射球)**: Hard Shoot。球速接近直球的噴射球。在實況野球中，有時位移明顯的二縫線直球 (Two-seamer) 也會被判定為高速噴射球，以反映其橫向竄動。
- **シンキングツーシーム (下沉二縫線)**: Sinking Two-seamer。帶有下沉尾勁的二縫線直球，軌跡介於噴射球與伸卡球之間。
