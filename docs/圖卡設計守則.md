# 實況野球致敬風球員卡設計規格書
版本：v1.0  
用途：作為 AI 圖像生成、視覺統一、球員卡模板製作之依據  
比例：1:1 正方形  
適用類型：投手版、野手版  
風格定位：**實況野球致敬風格（非直接複製） × 球探隨手筆記感 × 高辨識資訊卡**

---

## 1. 設計目標

本規格書的目標，是建立一套：

- **明顯讓人聯想到《實況野球》**
- 但**不直接複製官方 UI、字體、圖示、版面**
- 可長期套用於不同球員
- 可同時支援**投手版**與**野手版**
- 整體具備**鍵盤球探／球探隨手筆記**的氛圍
- 在社群貼文中可視性高、辨識快、資訊密度高

---

## 2. 風格定位

### 2.1 核心風格關鍵字
- 日系運動遊戲介面感
- 高彩度、圓角、粗線條
- 可愛但資訊化
- 規則清楚、結構明確
- 球探桌面筆記感
- 乾淨中帶少量手寫批註
- 非寫實、非美式金屬球員卡風
- 無球員照片
- 少量或不使用 icon

### 2.2 致敬來源的抽象特徵
可保留的辨識感來源：

- 飽和而明快的色塊
- 清楚的能力圖表
- 大數字能力值
- 膠囊型能力標籤
- 粗邊框、圓角模組
- 運動遊戲感的介面結構

必須避免的直接重現：

- 官方角色形象或吉祥物
- 官方 logo
- 官方字體直接仿製
- 官方能力面板 1:1 排版
- 官方特殊能力框樣式完全照搬
- 官方專有視覺資產

---

## 3. 卡片共通結構

所有球員卡必須使用**完全一致的版型骨架**，只允許中間主圖表模組因投手／野手不同而切換。

### 3.1 三大區塊
卡片由三個主要區塊構成：

1. **上方：球員基本資料區**
2. **中間：能力主視覺區**
3. **下方：特殊能力區**

### 3.2 高度比例建議
- 上方基本資料區：**22%～25%**
- 中間能力主視覺區：**40%～45%**
- 下方特殊能力區：**30%～35%**

### 3.3 版面原則
- 三區塊邊界明確
- 所有球員卡保持相同外框、間距、字級邏輯
- 投手版與野手版僅更換中段圖表內容
- 不因個別球員資料多寡改變版面骨架
- 所有欄位位置固定，避免每張卡長得不一樣

---

## 4. 整體視覺語言

### 4.1 外框
- 使用粗線條外框
- 外框需有圓角
- 可有輕微陰影，但避免厚重 3D 金屬感
- 建議外框顏色使用深藍、深灰藍、深綠藍等穩定色

### 4.2 背景
- 背景以**米白色、淡奶油白、淡紙張色**為主
- 可加入極淡紙張紋理
- 可加入淡淡的手帳／筆記紙感，但不得過於粗糙

### 4.3 視覺節奏
- 上方資訊區偏整齊
- 中間圖表區偏主視覺
- 下方技能區偏資訊密集
- 手寫註記只作點綴，不可壓過主資訊

---

## 5. 上方：球員基本資料區規格

### 5.1 必備內容
- 球員姓名（最大字）
- 英文名或羅馬拼音（次要字）
- 球隊名稱
- 背號
- 守位／角色
- 投打（例：右投右打）
- 年份版本（例：2026）
- 卡片類型（例：常態版、球探版、暫定版）

### 5.2 資訊排列建議
建議結構如下：

- 左側：姓名、英文名
- 中央：球隊／守位／投打
- 右側：背號／年份／卡片類型小標記

### 5.3 球員圖像
- **不使用真實球員照片**
- 可接受：
  - Q 版角色剪影，但避免接近實況野球
- 不建議：
  - 真實球員頭像或照片去背

### 5.4 icon 使用原則
- **少量或不使用 icon**
- 若使用，也應極簡化
- 不依賴 icon 傳達主要資訊
- 核心資訊必須靠文字與版面理解

---

## 6. 中間：能力主視覺區規格

此區是整張卡最重要的視覺重心。

### 6.1 共通規格
- 使用相同外框
- 區塊標題固定為：`能力分布 / Ability Profile`
- 框內主圖居中
- 可搭配少量手寫註記（1～3則）
- 右上角可有小型備註貼紙區，但不宜太大

---

## 7. 野手版中段規格

### 7.1 主圖表
使用**6 維雷達圖**

六項能力固定為：

1. 擊球（ミート）
2. 力量（パワー）
3. 走力
4. 肩力
5. 守備力
6. 捕球

### 7.2 呈現方式
- 雷達圖線條清楚
- 背景可有 4～5 層同心基準線
- 球員能力區塊可用半透明色面填色
- 外圈標籤需清楚可讀
- 可在各軸末端標註數值

### 7.3 輔助資訊
雷達圖周邊可搭配：
- 彈道
- 主守位
- 次守位
- 左右打／左右投
- 球探短評一行

### 7.4 不建議做法
- 不要把過多數值塞滿雷達圖周圍
- 不要用過度複雜的發光效果
- 不要加入過多裝飾圖示

---

## 8. 投手版中段規格

### 8.1 主圖表
使用**實況野球感的投手能力圖重新設計版**

結構原則：
- 中央為速球核心
- 周圍五個方向配置變化球
- 每個變化球用格數或段數表示變化量
- 必須讓人一眼理解這是投手球種分布圖
- 但圖形、格線、標示方式需重新設計，避免 1:1 複製原版

### 8.2 圖表內容
- 中央：速球／直球
- 周圍五方向：依球種分類顯示
- 每個球種顯示：
  - 球種名稱（日文）
  - 格數 / 等級
  - 必要時以短線、圓點、格子表示

### 8.3 右側能力欄
投手版中段右側可固定顯示三個大數值：

- 球速
- 控球
- 體力

顯示規則：
- 大字數值
- 小字標示能力名稱
- 可附等級（如 C / D / E）
- 三欄式或上下排列皆可，但需固定不變

### 8.4 輔助資訊
可補充：
- 先發 / 中繼 / 終結者類型
- 總變化量
- 主力球種摘要
- 球探短評一行

---

## 9. 下方：特殊能力區規格

### 9.1 區塊結構
下方特殊能力區分為兩層：

1. **技能標籤區**
2. **球探筆記區**

### 9.2 技能標籤區
- 使用膠囊形標籤
- 建議一次顯示 6～10 個
- 使用日文技能名稱
- 排列整齊，大小一致
- 可依類型區分顏色
- 技能名稱結尾為D（預設）時，可以不顯示

### 9.3 球探筆記區
此區用來呈現「少量球探隨手筆記感」。

風格要求：
- 少量，不可過多
- 每張卡以 **1～3 則短筆記** 為原則
- 可用鉛筆、藍筆、紅筆的感覺
- 可有箭頭、圈選、底線、簡短吐槽

內容可包括（配合特能）：
- 「先發樣本仍少」
- 「對左打有壓制力」
- 「球速後段略降」
- 「短打處理穩」
- 「拉打長打型」
- 「K/BB普通但結果佳」

### 9.4 筆記呈現限制
- 筆記不是主角，只能輔助
- 不可蓋住技能標籤
- 不可造成整體畫面雜亂
- 保持“像有做註記”，不是“整張都在亂畫”

## 10. 配色規格

### 10.1 核心方向
配色需讓人聯想到實況野球系 UI，但避免使用完全相同的官方色碼。

總體原則：
- 高彩度
- 色塊明快
- 清楚分區
- 同色相家族微調
- 可作為長期模板配色基礎

### 10.2 基礎主色建議
- 天空藍：`#56BFE8`
- 亮黃：`#F7D44A`
- 活力紅：`#F25C54`
- 草綠：`#67C96B`
- 深海軍藍：`#285A84`
- 米白底：`#FAF7EF`
- 淺灰藍：`#DDE7F0`
- 深灰藍線條：`#30485C`

### 10.3 等級色建議
可用於評級字母、數值小色條等：

- A：金黃系
- B：橘黃系
- C：亮綠系
- D：天藍系
- E：藍灰系
- F：灰色或偏暗紅灰
- G：更深灰或暗紅灰

### 10.4 技能標籤配色
- 正向技能：亮藍底、白字
- 稀有／金特：金黃底、深色字
- 負向技能：紅底、白字
- 戰術／輔助類：綠底、白字
- 中性文字籤：灰藍底、深字

## 11. 中職六隊配色延伸規格（預留）

目前可先採**中性共通模板**，未來再延伸六隊版本。

### 11.1 建議策略
先做一套不綁隊的母模板，再依球隊替換：

- 標題條色
- 邊框高亮色
- 雷達圖或投手圖主填色
- 特殊能力區輔助色
- 球員姓名底板小色條

### 11.2 六隊版本建議做法
不要直接照搬球隊官方 CI，而是做「參考色系」。

例如：
- 中信兄弟：黃 / 深藍
- 統一獅：橘 / 黑
- 樂天桃猿：酒紅 / 桃紅 / 白
- 富邦悍將：深藍 / 紅
- 味全龍：紅 / 米白 / 黑
- 台鋼雄鷹：綠 / 黃綠 / 深灰

### 11.3 建議流程
- 第一步：完成中性母模板
- 第二步：建立六隊色系對照表
- 第三步：只換色，不改版型
- 第四步：確認所有隊版仍有一致性

## 12. 字體規格

### 12.1 整體字體氣質
- 中文：粗圓體或圓角黑體
- 英文與數字：圓角無襯線體
- 手寫筆記：模擬原子筆／鉛筆手寫感

### 12.2 字級階層
建議至少區分四層：

1. 球員姓名（最大）
2. 區塊標題
3. 主要能力數值
4. 輔助資訊與技能標籤字

### 12.3 字體使用原則
- 不可混用過多字體
- 正式資訊字體需統一
- 手寫字體僅限筆記區與局部註記
- 數值需清楚、厚實、易讀

---

## 13. 一致性規範（非常重要）

所有球員卡都必須遵守以下一致性原則：

### 13.1 固定不變項
- 畫面比例固定 1:1
- 三區塊比例固定
- 外框樣式固定
- 區塊標題位置固定
- 字級層級固定
- 技能標籤尺寸固定
- 背景紙感固定
- 球探筆記量控制固定

### 13.2 可變項
- 球員資料文字
- 能力值
- 雷達圖形狀
- 投手球種格數
- 技能標籤內容
- 球探筆記內容
- 隊伍配色版本

### 13.3 禁止事項
- 每張卡自由變換版型
- 忽大忽小的技能標籤
- 某些卡片使用大量 icon、某些完全不用
- 有些卡寫實、有些卡卡通
- 有些卡手寫很多、有些完全沒有
- 中段圖表位置飄移

---

## 14. 視覺密度與筆記量控制

### 14.1 原則
使用者已選定為：
- **方案二：球探筆記版**
- 但要求**不要太多**
- 因為可搭配貼文文字補充

### 14.2 實際執行標準
- 每張卡最多 1～3 處手寫筆記
- 每張卡最多 2～4 個手寫視覺元素（箭頭、圈選、底線）
- 不使用大面積塗鴉
- 不做滿版批註
- 讓卡片保有正式球員卡感，再加少量球探味

---

## 15. 圖像生成提示語設計原則

本規格未直接提供最終 prompt，但之後撰寫 prompt 時應遵守下列原則：

### 15.1 必寫內容
- 1:1 square format
- baseball player card
- homage to Japanese baseball video game UI
- original redesign, not a direct copy
- clean modular layout
- top info section, middle chart section, bottom skill section
- scout memo aesthetic
- no player photo
- minimal or no icons
- bold rounded UI
- bright colorful palette
- paper texture background
- Japanese skill labels

### 15.2 投手版必寫關鍵
- pitcher ability chart inspired by classic Japanese baseball game
- central fastball with surrounding pitch directions
- large speed / control / stamina numbers
- pitch type labels in Japanese

### 15.3 野手版必寫關鍵
- six-axis radar chart
- contact, power, speed, arm, fielding, catching
- large clean radar chart
- supportive small labels

### 15.4 避免關鍵
- direct replica
- official logo
- copyrighted character style
- exact UI duplication
- screenshot-like reproduction

## 16. 推薦母模板描述（摘要）

可將此作為後續 prompt 的母概念：

> 一張 1:1 正方形的日本運動遊戲風棒球球員卡，整體具有高彩度、圓角、粗線條與資訊化版面，致敬《實況野球》但為原創改編設計。卡片分為三個固定區塊：上方是球員基本資料，中間是能力主視覺區（野手為 6 維雷達圖，投手為重新設計的變化球方向圖與球速／控球／體力數值），下方為日文特殊能力標籤與少量球探手寫筆記。背景為米白紙張質感，整體乾淨、可愛、清楚、有少量球探隨手註記，不使用球員照片，少量或不使用 icon。

## 17. 目前版本結論

本案目前已確定：

- 走 **球探筆記版**
- 但筆記量控制在少量
- 野手使用 **6 維雷達圖**
- 投手中段要有 **球速／控球／體力**
- 特殊能力使用 **日文**
- icon 採 **少量甚至不使用**
- 可先做 **中性母模板**
- 六隊版本建議作為第二階段配色延伸
