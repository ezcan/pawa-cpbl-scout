# ⚾ 實況野球 CPBL 球探 AI (PawaPro CPBL Scout Agent)

這是一個基於 LLM（大型語言模型）的 Prompt Engineering 專案，旨在打造一位專屬的「鍵盤球探」，將中華職棒 (CPBL) 或其他聯盟的真實球員數據，客觀、合理且嚴謹地轉換為《實況野球 2026-2027》（パワフルプロ野球）遊戲中的數值與特殊能力。

## ✨ 專案特色

*   **專屬人設「影山秀逗」**：扮演遊戲神級球探影山秀路的弟弟，以帶有 PTT/Dcard 鄉民口吻、愛看進階數據的「冷氣房鍵盤球探」身分與使用者互動，兼具專業與趣味。
*   **嚴謹的脫水機制**：內建中職一軍成績至日職環境的轉換標準，拒絕無腦發放 S 級與金特，極力維持遊戲生態平衡。
*   **完整的新秀查定**：針對只有二軍數據或剛選秀入團的「天賦原石」，設有專屬的嚴格查定規則，精準還原遊戲中新秀的生澀感。
*   **完整的遊戲字典**：內附《實況野球》最新的特殊能力與變化球種白名單，防止 AI 隨意幻想不存在的技能。

## 📂 專案結構

```text
pawa-cpbl-scout/
├── prompt/
│   └── scout-agent.md   # 主系統提示詞 (System Prompt)，定義 AI 人設、查定原則與最終輸出格式。
├── docs/
│   ├── 基礎能力.md      # (文件 A) 野手/投手各項基礎能力的給分標準、邊界限制與中職專用轉換表。
│   ├── 特殊能力.md      # (文件 B) 遊戲內所有金特、青特、赤特與綠特的技能說明。
│   └── 變化球種.md      # (文件 C) 遊戲內合法的變化球種名稱對照表。
└── README.md
```

## 🚀 如何使用 (Usage)

本專案適用於支援「系統提示詞」或「知識庫上傳」的大型語言模型（推薦使用 Claude 3.5 Sonnet、ChatGPT Plus (GPT-4o) 或 Gemini 1.5 Pro 等高階模型）。

### 方法一：建立自訂 GPTs 或 Claude Project (推薦)
1. 建立一個新的 AI 助理專案。
2. 將 `prompt/scout-agent.md` 的內容完整貼入「系統提示詞 (System Instructions)」欄位。
3. 將 `docs/` 資料夾下的三個 Markdown 檔案上傳至該助理的「知識庫 (Knowledge Base)」。
4. 儲存後，直接在對話框輸入中職球員名稱（例如：「幫我查定 2024 年的古林睿煬」或「評估第一指名新秀」），AI 就會開始為您工作。

### 方法二：單次對話貼上
若您使用一般的聊天視窗：
1. 先將 `docs/` 內的三個文件內容貼給 AI，告訴它：「請將這些作為接下來對話的知識庫文件 A、文件 B 與文件 C」。
2. 接著貼上 `prompt/scout-agent.md` 的內容，啟動「影山秀逗」的人設。
3. 開始輸入球員名稱進行查定。

## ⚠️ 查定注意事項與免責聲明

*   **作者個人標準**：本專案的查定尺度與換算公式，完全是作者 **EZCAN** 基於「不破壞遊戲平衡」與「對齊日職常態分佈」的前提下所設計的**個人主觀標準**。產出的遊戲數值與能力評級**絕非等同於現實中選手的真實表現與絕對實力**，請勿將其作為評價真實球員強弱的唯一依據。

*   **保守為上**：本 Prompt 核心精神為「保守」，即使是頂尖中職球員，在放到日職環境的尺度下，多數能力會落在 C~E 之間，這是為了維持與原版日職球員同場競技時的和諧度。
*   **幻覺防範**：遇到 AI 給出異常高分或奇怪的球種時，可要求 AI 重新檢視「文件 A」或「文件 C」的限制。
*   **數據來源**：AI 預設會上網檢索中華職棒官網、野球革命與維基館等來源，但有時 AI 的搜尋能力會受限，若發現數據不準確，建議使用者可以直接把數據貼給 AI 參考。
